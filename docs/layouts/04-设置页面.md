# 04 · 设置页面（Settings）

设置页只解决“模型能否正确调用”这一件事。

## 1. 整体布局

```text
┌────────────────────────────────────────────┐
│  ← 关闭              模型设置              │
├────────────────────────────────────────────┤
│                                            │
│  API Key                                  │
│  ┌──────────────────────────────────────┐  │
│  │ •••••••••••••••••••••••            │  │
│  └──────────────────────────────────────┘  │
│                                            │
│  模型                                      │
│  ┌──────────────────────────────────────┐  │
│  │ qwen-plus                           │  │
│  └──────────────────────────────────────┘  │
│  可输入任意 OpenAI 兼容模型名称             │
│                                            │
│  Base URL                                 │
│  ┌──────────────────────────────────────┐  │
│  │ https://.../compatible-mode/v1      │  │
│  └──────────────────────────────────────┘  │
│  文章正文和划词内容将发送到 api.example.com │
│  模型端点权限：已允许                       │
│                                            │
│  [清除 API Key]       [测试连接]   [保存]   │
│  ● 连接成功：模型可以正常响应               │
└────────────────────────────────────────────┘
```

## 2. 表单字段

- API Key：必填，本地保存；界面默认隐藏具体内容。
- 模型：可自由输入，并提供 `qwen-plus`、`qwen-max` 等常用建议。
- Base URL：必填，保存时去除路径末尾多余 `/`；正式端点只允许 HTTPS。
- `localhost` 和 `127.0.0.1` 可使用 HTTP 调试，界面会标记为“不安全的本机 HTTP 调试连接”。
- Base URL 下方实时显示文章正文和划词内容将发送到的规范化主机。
- 同一区域显示当前主机权限状态；未允许时提示通过“测试连接”或“保存”重新申请。

不增加服务商管理、多个配置方案或高级参数。

## 3. 测试连接

- 使用当前表单值发起最小请求，不要求先保存。
- 发起请求前申请当前 Base URL 对应的单个主机权限；拒绝后不连接模型，并说明如何再次授权。
- 测试期间按钮显示“测试中…”，并防止重复提交。
- 成功时提示模型可以正常响应。
- 失败时区分不安全端点、地址无效、网络失败、认证失败和模型不存在等常见问题。
- 测试结果不产生文章记录。

## 4. 保存

- 保存前校验三个字段。
- 校验后申请当前 Base URL 对应的单个主机权限；拒绝后保持已保存配置不变。
- 普通 HTTP 端点不能保存；后台配置写入与翻译请求复用同一端点规则。
- 保存成功后保留在当前页面并显示反馈。
- 连接测试和保存互相独立：测试不会自动保存，保存也不会自动调用模型。

## 5. 清除 API Key

- 首次点击进入确认状态，再次点击后删除本地保存的 API Key 并清空表单字段。
- 模型、Base URL、文章结果和历史保持不变。
- 不提供固定口令“加密”；界面明确说明 Key 仅保存在本地浏览器中。
