# 翻译结果页

翻译结果的展示页面。核心是通过 `md-wx` 组件以打字机效果渲染 Markdown，并提供复制与下载。

## 1. 整体布局

```
┌──────────────────────────────────────────────────┐
│  ← 返回   网页翻译结果           [复制] [下载]   │  ← 顶栏
├──────────────────────────────────────────────────┤
│                                                  │
│  # 文章标题                                      │  ← 文章元信息
│  > 作者：张三                                    │
│  > 原文链接：https://example.com/article         │
│  ────────────────────────────────────────────── │
│                                                  │
│  这是翻译后的正文内容，正在逐字显示...▊           │  ← 正文渲染区
│                                                  │  （打字机 + md-wx）
│  第二段内容持续追加...                           │
│                                                  │
│  ![图片描述](https://example.com/img.png)        │
│                                                  │
└──────────────────────────────────────────────────┘
```

## 2. 模块划分

### 2.1 顶栏

- 左侧：返回按钮 + 页面标题。
- 右侧：复制按钮、下载按钮。

```
│  ← 返回   网页翻译结果           [复制] [下载]   │
```

### 2.2 文章元信息

- 按需求固定格式展示标题、作者、原文链接（`>` 引用形式）。

```
│  # 文章标题                                      │
│  > 作者：张三                                    │
│  > 原文链接：https://example.com/article         │
```

### 2.3 正文渲染区

- 由 `md-wx` 组件渲染 Markdown 正文。
- 流式翻译增量逐块追加，实现打字机效果（光标 `▊` 表示输出中）。
- 原文图片以 `![alt](src)` 形式保留并渲染。

```
│  这是翻译后的正文内容，正在逐字显示...▊           │
│                                                  │
│  ![图片描述](https://example.com/img.png)        │
```

## 3. 交互说明

| 操作 | 行为 |
|------|------|
| 点击「← 返回」 | 关闭结果页，回到弹窗 |
| 点击「复制」 | 复制完整 Markdown 结果 |
| 点击「下载」 | 下载结果 `.md` 文件 |
| 翻译中 | 正文区打字机逐字展示，光标闪烁 |
