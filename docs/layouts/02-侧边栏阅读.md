# 02 · 侧边栏阅读（Side Panel）

Side Panel 是 Demo 的主要界面。用户可以一边保留原网页，一边查看翻译和处理阅读中的临时问题。

## 1. 文章阅读视图

```text
┌────────────────────────────────────┐
│  文章阅读助手                       │
│  历史  ↗原文  设置  [复制 ▾] [下载] │  ← 吸顶页头
├────────────────────────────────────┤
│  How JavaScript Works              │
│  example.com · 作者名称             │
│                                    │
│  38,000 字符 · 长文章 · 112 个块      │  ← 文章规模预检
│                                    │
│  ● 正在翻译第 3/8 段       [取消]    │  ← 状态与控制
│                                    │
│  [仅译文] [双语对照] [仅原文]       │  ← 阅读模式
├────────────────────────────────────┤
│  译文                              │
│  JavaScript 引擎首先解析源代码……▊   │
│                                    │
│  ## 执行上下文                     │
│  接着，引擎会创建执行上下文……       │
│                                    │
│            （文章可独立滚动）       │
└────────────────────────────────────┘
```

## 2. 双语模式

Demo 阶段采用“完整原文在上、完整译文在下”，不做逐段强制对齐。

```text
┌────────────────────────────────────┐
│  原文                              │
│  JavaScript engines first parse... │
│  ...                               │
│  ────────────────────────────────  │
│  译文                              │
│  JavaScript 引擎首先解析……          │
│  ...                               │
└────────────────────────────────────┘
```

- “仅译文”是默认模式。
- “双语对照”同时显示完整原文和译文。
- “仅原文”便于检查正文提取结果。
- 最后一次选择保存在本地，重新打开后恢复。

## 3. 翻译状态与操作

正文可用后先显示 Unicode 字符数和 Markdown 块数；超过 30,000 字符时标记为“长文章”，并提示将按 Markdown 结构顺序分段。普通文章保持一次请求，长文章的各片段严格串行并显示真实的 N/M 进度。

| 状态 | 界面操作 |
|------|----------|
| 读取中 | 显示“正在读取文章”，禁用输出操作 |
| 翻译中 | 流式展示译文；多段文章显示“正在翻译第 N/M 段”和“取消” |
| 已完成 | 显示完成状态，可复制、下载或重新翻译 |
| 已取消 | 保留已完成段，显示“继续翻译”和“重新翻译” |
| 失败 | 显示失败段和已完成段数；结构校验失败也可从首个未完成段继续 |
| 空内容 | 提示用户回到文章页从 Popup 发起翻译 |

不显示无法准确计算的百分比进度。

## 4. 划词翻译卡片

右键翻译选中文字后，在文章视图顶部显示临时卡片，不覆盖文章内容。

```text
┌────────────────────────────────────┐
│  划词翻译                     ×    │
│  原文：The browser parses HTML...  │
│  译文：浏览器会解析 HTML……          │
│                         [复制译文]  │
└────────────────────────────────────┘
```

- 连续发起时替换上一条临时划词结果。
- 关闭卡片后返回原来的文章滚动位置。
- Demo 阶段不保存划词历史。

## 5. 历史视图

点击顶栏“历史”后，在同一侧边栏切换视图。

```text
┌────────────────────────────────────┐
│  ← 返回阅读        最近阅读（20）  │
├────────────────────────────────────┤
│  How JavaScript Works              │
│  example.com · 今天 15:30     [删] │
├────────────────────────────────────┤
│  Building a Tiny Compiler          │
│  example.org · 昨天 21:10     [删] │
└────────────────────────────────────┘
```

- 最新记录在最上方。
- 点击记录回到文章阅读视图，不重新调用模型。
- 单条删除需要再次点击“确认删除”；删除当前结果后，阅读视图同步到剩余的最新记录，没有记录时显示空状态。
- 只保留最近 20 篇，不做搜索、收藏和分页。

## 6. 输出操作

- 输出操作位于吸顶页头，窄宽时自动换到标题下一行。
- 复制选项：仅译文 Markdown、双语 Markdown。
- 复制内容始终包含标题、作者和原文链接，不受当前阅读模式影响；完成后显示成功或失败反馈。
- 下载固定输出双语 Markdown，内容与“双语 Markdown”复制一致；文件名来自清理后的文章标题。
- 翻译未完成时禁用依赖完整结果的操作。
- Side Panel 和 Result 复用相同输出逻辑。

## 7. 窄宽适配

- 侧边栏较窄时，页头操作换行显示，正文仍占满可用宽度。
- 模式按钮保持一行，文本可缩短为“译文 / 双语 / 原文”。
- Markdown 表格和代码块允许横向滚动，不撑破侧边栏。
- 长标题、来源链接和划词内容允许断行，不撑破侧边栏。
