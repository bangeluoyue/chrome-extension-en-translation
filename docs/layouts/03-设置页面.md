# 设置页面

用于配置调用 AI 翻译所需的 API Key 与模型参数。保持极简，仅保留必要配置项。

## 1. 整体布局

```
┌──────────────────────────────────────────────┐
│  ← 返回              设置                    │  ← 顶栏
├──────────────────────────────────────────────┤
│                                              │
│  API Key                                    │
│  ┌────────────────────────────────────────┐  │
│  │ sk-xxxxxxxxxxxxxxxx                    │  │  ← 表单区
│  └────────────────────────────────────────┘  │
│                                              │
│  模型                                       │
│  ┌────────────────────────────────────────┐  │
│  │ qwen-plus                          ▼   │  │
│  └────────────────────────────────────────┘  │
│                                              │
│  Base URL                                   │
│  ┌────────────────────────────────────────┐  │
│  │ https://dashscope.aliyuncs.com/...     │  │
│  └────────────────────────────────────────┘  │
│                                              │
│  ┌────────────────────────────────────────┐  │
│  │               保存                     │  │  ← 保存按钮
│  └────────────────────────────────────────┘  │
└──────────────────────────────────────────────┘
```

## 2. 模块划分

### 2.1 顶栏

- 左侧返回按钮，中间标题「设置」。

```
│  ← 返回              设置                    │
```

### 2.2 表单区

- API Key：必填，明文输入，保存于本地存储。
- 模型：下拉选择，默认 `qwen-plus`，可选 `qwen-max` 等。
- Base URL：提供默认值（OpenAI 兼容端点），可修改以切换厂商。

```
│  API Key                                    │
│  ┌────────────────────────────────────────┐  │
│  │ sk-xxxxxxxxxxxxxxxx                    │  │
│  └────────────────────────────────────────┘  │
```

### 2.3 保存

- 点击保存后将配置写入本地存储并提示成功。

```
│  ┌────────────────────────────────────────┐  │
│  │               保存                     │  │
│  └────────────────────────────────────────┘  │
```

## 3. 交互说明

| 操作 | 行为 |
|------|------|
| 点击「← 返回」 | 返回弹窗 |
| 点击「保存」 | 持久化 API Key / 模型 / Base URL 配置 |
