# 01 · 弹窗页面（Popup）

Popup 是轻量启动器，不承载长文章、流式翻译和下载功能。

## 1. 默认布局

```text
┌──────────────────────────────────┐
│  AI 文章阅读助手          ⚙ 设置 │
├──────────────────────────────────┤
│  当前网页                        │
│  ┌────────────────────────────┐  │
│  │ How JavaScript Works       │  │
│  │ example.com                │  │
│  └────────────────────────────┘  │
│                                  │
│  ┌────────────────────────────┐  │
│  │      在侧边栏翻译文章       │  │
│  └────────────────────────────┘  │
│                                  │
│  最近阅读                        │
│  Building a Tiny Compiler   ›   │
│                                  │
│  准备就绪                        │
└──────────────────────────────────┘
```

## 2. 模块

### 顶栏

- 显示产品名称。
- “设置”打开 Settings 页面。

### 当前网页卡片

- 显示当前标签页标题和站点域名。
- 只展示两行摘要，不在 Popup 中预览完整 Markdown。
- 不可提取的页面直接显示原因。

### 主操作

- “在侧边栏翻译文章”是唯一主按钮。
- 点击后以当前标签页临时权限注入正文提取脚本、保存待翻译文章并打开 Side Panel。
- 普通浏览时不预先注入脚本，也不持有所有站点的长期读取权限。
- Side Panel API 打开失败时进入 Result 页面。

### 最近阅读

- 有历史时只显示最新一篇，点击后在 Side Panel 打开。
- 无历史时隐藏该区域，不显示无意义占位。

### 状态提示

- 展示“准备就绪”“正在提取”“请先配置模型”或提取错误。
- 错误提示包含下一步操作。

## 3. 主要状态

```text
未配置： [先去设置]
提取中： [正在提取…]（按钮禁用）
提取失败：当前页面无法识别正文，请换文章页或刷新重试
```

## 4. 交互边界

| 操作 | 结果 |
|------|------|
| 点击主按钮 | 提取当前文章并打开 Side Panel |
| 点击最近阅读 | 在 Side Panel 打开最新结果，不重新翻译 |
| 点击设置 | 打开 Settings |

Popup 不提供原文预览、翻译正文、复制和下载，避免与 Side Panel 重复。
