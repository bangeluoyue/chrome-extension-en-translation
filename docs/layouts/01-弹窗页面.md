# 弹窗页面（Popup）

插件主入口。用户点击浏览器工具栏图标时弹出，聚焦「一键翻译」与「下载」两个核心动作，简约无冗余。

## 1. 整体布局

```
┌──────────────────────────────────────────┐
│  网页翻译                        ⚙ 设置  │  ← 顶栏
├──────────────────────────────────────────┤
│                                          │
│  当前页面                                 │
│  ┌────────────────────────────────────┐  │
│  │ 文章标题（提取后显示，最多两行）     │  │  ← 当前页面信息
│  │ 提取状态：已就绪 / 提取中...        │  │
│  └────────────────────────────────────┘  │
│                                          │
│  ┌────────────────────────────────────┐  │
│  │            一键翻译                │  │  ← 一键翻译按钮（主操作）
│  └────────────────────────────────────┘  │
│                                          │
│  ┌────────────────────────────────────┐  │
│  │         下载 Markdown             │  │  ← 下载按钮（次操作）
│  └────────────────────────────────────┘  │
│                                          │
│  提示：翻译完成后即可下载                │  ← 状态提示区
└──────────────────────────────────────────┘
```

## 2. 模块划分

### 2.1 顶栏

- 左侧：插件名称「网页翻译」。
- 右侧：设置图标，点击跳转至设置页面。

```
┌──────────────────────────────────────────┐
│  网页翻译                        ⚙ 设置  │
└──────────────────────────────────────────┘
```

### 2.2 当前页面信息

- 展示当前标签页提取到的文章标题（提取成功后回填）。
- 附带提取状态提示（已就绪 / 提取中 / 失败）。

```
│  当前页面                                 │
│  ┌────────────────────────────────────┐  │
│  │ 文章标题（提取后显示，最多两行）     │  │
│  │ 提取状态：已就绪 / 提取中...        │  │
│  └────────────────────────────────────┘  │
```

### 2.3 一键翻译

- 主操作按钮，占据主要视觉权重。
- 点击后触发：提取正文 → 调起翻译结果页并开始流式翻译。

```
│  ┌────────────────────────────────────┐  │
│  │            一键翻译                │  │
│  └────────────────────────────────────┘  │
```

### 2.4 下载 Markdown

- 次操作按钮。
- 将最近一次翻译结果按固定格式下载为 `.md` 文件；无结果时置灰禁用。

```
│  ┌────────────────────────────────────┐  │
│  │         下载 Markdown             │  │
│  └────────────────────────────────────┘  │
```

### 2.5 状态提示区

- 展示进度与错误信息（如「提取中…」「翻译完成」「API Key 未配置」等）。

```
│  提示：翻译完成后即可下载                │
```

## 3. 交互说明

| 操作 | 行为 |
|------|------|
| 点击「一键翻译」 | 提取当前页面正文并打开翻译结果页开始流式翻译 |
| 点击「下载 Markdown」 | 下载最近一次翻译结果为 `.md` 文件 |
| 点击「⚙ 设置」 | 进入设置页面 |
