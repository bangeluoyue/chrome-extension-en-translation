# 03 · 翻译结果页（Result）

Result 是 Side Panel 的宽屏降级页面，不维护第二套翻译数据和交互逻辑。

## 1. 整体布局

```text
┌────────────────────────────────────────────────────────────┐
│  ← 关闭   文章阅读助手       ↗ 打开原文   [复制 ▾] [下载] │
├────────────────────────────────────────────────────────────┤
│  How JavaScript Works                                      │
│  example.com · 作者名称                                    │
│                                                            │
│  12,480 字符 · 普通文章 · 36 个 Markdown 块                 │
│                                                            │
│  ● 翻译完成        [仅译文] [双语对照] [仅原文] [重新翻译] │
│  ────────────────────────────────────────────────────────  │
│                                                            │
│  翻译后的 Markdown 正文……                                 │
│                                                            │
└────────────────────────────────────────────────────────────┘
```

## 2. 与 Side Panel 共用的能力

- 文章标题、作者和原文链接。
- 翻译状态、流式内容和重新翻译。
- 三种阅读模式。
- 与 Side Panel 相同的文章规模反馈、真实分段进度和本地断点恢复行为。
- 仅译文/双语 Markdown 复制和双语 Markdown 下载。

这些能力应复用同一组件和工具函数，Result 只调整容器宽度与导航按钮。

## 3. Result 独有行为

- “关闭”关闭当前扩展页面。
- 内容区域使用更宽的阅读宽度。
- 不展示划词卡片和历史列表；这些功能仍归 Side Panel。
- Side Panel 打开失败时自动进入本页。

## 4. 状态布局

加载、翻译、取消、失败和空内容状态与 Side Panel 使用相同文案和操作，不维护另一套状态定义。取消、模型错误或 Markdown 结构校验失败时保留已完成段；“继续翻译”从首个未完成段恢复，“重新翻译”清除旧检查点。
