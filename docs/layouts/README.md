# Demo 页面布局说明

> 依据：[proposal.md](../proposal.md)、[design.md](../design.md)

## 1. 布局目标

界面围绕“阅读当前文章”设计。Popup 只负责启动，Side Panel 是主要工作区，Result 是宽屏降级页面，Settings 只保留模型配置。

划词翻译和最近历史都放在 Side Panel 内，不为它们增加独立页面，避免重复导航和重复组件。

## 2. 页面清单

| 页面 | 说明 |
|------|------|
| [01 · Popup](./01-弹窗页面.md) | 查看当前网页并打开阅读侧边栏 |
| [02 · Side Panel](./02-侧边栏阅读.md) | 翻译、双语阅读、划词和最近历史的主要界面 |
| [03 · Result](./03-翻译结果页.md) | Side Panel 不可用时的降级入口，也可宽屏阅读 |
| [04 · Settings](./04-设置页面.md) | 编辑模型配置并测试连接 |
| [05 · 稳定性与隐私交互](./05-稳定性与隐私交互.md) | 已实现文章规模、分段恢复、结构保护、端点最小权限和容量反馈 |

## 3. 共享布局规则

- 主操作每个区域只保留一个，其他操作降低视觉权重。
- 长文章的复制与下载入口保留在吸顶页头，用户不必滚回顶部。
- 加载、翻译中、完成、取消、失败和空内容均有文字状态。
- Side Panel 与 Result 在正文可用后显示相同的文章规模和长文章风险。
- Side Panel 与 Result 复用阅读内容、模式切换和输出操作，不复制业务逻辑。
- 新功能优先放进已有区域，只有职责明显不同才新增组件。

## 4. 页面关系

```text
Popup ──一键翻译──► Side Panel ◄──右键划词── Web Page
  │                     │
  └──────设置──────────► Settings

Side Panel 打开失败 ──► Result
Side Panel / Result ──► 原文网页
```

## 5. 功能归属

| 功能 | 唯一主入口 |
|------|------------|
| 翻译当前文章 | Popup |
| 阅读与翻译控制 | Side Panel |
| 划词结果 | Side Panel |
| 最近 20 篇历史 | Side Panel 的历史视图 |
| 复制与下载 | Side Panel / Result 的共享操作栏 |
| 模型配置与连接测试 | Settings |
