## 2. 模块总览

| 模块 | 所属页面 | 职责 |
|------|----------|------|
| 顶栏 | 弹窗 / 结果 / 设置 | 标题、返回、设置入口、复制/下载入口 |

| 表单区 | 设置 | 配置 API Key、模型、BaseURL |
| 保存 | 设置 | 持久化配置 |

## 3. 实现步骤规划

按「底层能力 → 页面」的顺序推进，共 5 个阶段。

### 阶段一：项目初始化

1. 初始化工程：创建扩展目录结构（依据 design.md 目录规范）。
2. 安装依赖：React、TypeScript、Vite、`@mozilla/readability`、`turndown`、`openai`、`md-wx` 等。
3. 配置 Manifest V3 与多入口构建（background / content / popup / 结果页 / 设置页）。

### 阶段二：基础设施

1. 定义统一类型：消息协议、提取结果、翻译请求/结果、存储结构。
2. 搭建 Background Service Worker：消息路由与存储读写。
3. 搭建存储服务：`chrome.storage.local` 保存最近一次翻译结果与用户配置。

### 阶段三：核心能力

1. 内容提取（Content Script）：Readability 抽取正文 → Turndown 转 Markdown → 提取标题/作者/链接/图片。
2. AI 翻译：OpenAI SDK 兼容调用 Qwen，流式输出。
3. 下载：将最终 Markdown 拼接为固定格式并下载为 `.md` 文件。

### 阶段四：页面实现

1. 实现弹窗页面（一键翻译 / 下载 / 状态）。
2. 实现翻译结果页（打字机 + md-wx 渲染 + 复制/下载）。
3. 实现设置页面（API Key / 模型配置）。

### 阶段五：联调与验收

1. 端到端联调：提取 → 翻译 → 展示 → 下载。
2. 按 proposal.md 验收标准逐项核对。
