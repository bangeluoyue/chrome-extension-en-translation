# 基于 Chrome 的网页翻译浏览器插件 — 需求文档

## 1. 项目概述

本项目旨在开发一款 Chrome 浏览器翻译插件。用户在浏览任意英文网站时，可通过本插件将当前页面的主要文章内容提取出来，转换为 Markdown 格式，并调用 AI 大模型进行翻译，最终以类似 ChatGPT 的打字机效果动态展示翻译结果。

## 2. 目标用户与使用场景

- **目标用户**：需要阅读英文文章、新闻、博客、技术文档等内容的中文用户。
- **使用场景**：用户打开任意英文文章页面，点击插件按钮，插件自动提取正文并翻译，用户以 Markdown 形式查看翻译结果。

## 3. 功能需求

### 3.1 文章内容提取

- 用户在浏览任意英文网站时，插件能够识别并提取当前页面的**主要文章内容**（正文部分），过滤导航栏、侧边栏、广告、页脚等无关内容。
- 提取结果需要转换为 **Markdown 格式**，保留原文的标题、段落、列表、链接、加粗、引用等基本结构。

### 3.2 图片处理

- 原文中的图片需被转换为 Markdown 图片格式：`![alt](src)`。
- `alt` 为图片的替代文本（可为空或使用原文图片描述）。
- `src` 为图片的原始 URL 地址。

### 3.3 AI 大模型翻译

- 将提取出的 Markdown 正文内容发送给 AI 大模型进行翻译（英译中）。
- 翻译需保留 Markdown 结构，图片、链接等格式在翻译后不应丢失。

### 3.4 打字机动态展示

- 翻译结果需以类似 ChatGPT 的**打字机效果**（逐字/逐段动态输出）进行展示，而非一次性全部显示。
- 展示过程中用户应能感知翻译正在持续进行。

### 3.5 本地持久化存储

- 无需历史记录功能。
- 仅需在本地持久化存储用户**最近一次**的翻译结果。
- 用户再次打开插件时，应能恢复展示最近一次翻译结果。

### 3.6 最终输出格式

最终输出的内容需遵循以下固定格式：

```
# [文章标题]

> **作者**：[作者名]
> **原文链接**：[原始文章URL]

[翻译后的正文]
```

- `[文章标题]`：原文文章标题。
- `[作者名]`：原文作者名（若无法识别，可为空或显示"未知"）。
- `[原始文章URL]`：当前页面的原始 URL。
- `[翻译后的正文]`：翻译后的正文内容，以 Markdown 格式呈现。

## 4. 非功能需求

- **兼容性**：需兼容主流的 Chrome 浏览器版本。
- **易用性**：用户操作步骤应尽可能简单，一键完成提取与翻译。
- **隐私性**：翻译结果仅保存在本地，不涉及云端历史同步。

## 5. 边界与限制（本期不做）

- 不做历史记录功能。
- 不做多语言互译，本期仅支持英译中。
- 不做云端同步与账号体系。
- 不做文章内容的编辑与导出（本期仅展示，导出能力可后续扩展）。

## 6. 验收标准

1. 在任意英文文章页面，可一键提取主要正文并生成 Markdown。
2. 原文图片正确转换为 `![alt](src)` 格式。
3. 翻译结果以打字机效果动态展示。
4. 输出内容格式严格符合 3.6 节规定的格式。
5. 最近一次翻译结果可在本地持久化保存，并在下次打开时恢复。
